# SEC Filings RAG: Public Demo

A public, no-install demo of the [SEC Filings RAG](https://github.com/DiegoTDDD/sec-filings-rag) system.

The full system needs local services (Qdrant and Ollama) that a free cloud host cannot run. This demo therefore serves answers that were generated ahead of time by the real pipeline and saved in `demo_data.json`. The answers and their cited sources are genuine outputs of the RAG; the app only displays them.

**Live demo:** https://sec-filings-rag-demo.streamlit.app

## Why this is a separate repository

The main project pins about 150 packages (including PyTorch), which a free host should not install just to display precomputed answers. This repository only needs `streamlit` (see `requirements.txt`). `demo_app.py` and `demo_data.json` are copies of `dashboard/demo_app.py` and `dashboard/demo_data.json` from the [main repository](https://github.com/DiegoTDDD/sec-filings-rag), where the answers are generated by `src/retrieval/precompute_demo.py`. To refresh the demo, follow [Refreshing the public demo](https://github.com/DiegoTDDD/sec-filings-rag#refreshing-the-public-demo) in the main README.

## Run locally

```bash
pip install -r requirements.txt
streamlit run demo_app.py
```

## Automated checks

- **Security audit** (`security-audit.yml`) audits every `requirements*.txt` with `pip-audit` whenever dependencies change and every Monday. It fails only when a vulnerable package has a fixed version available.
- **App health** (`app-health.yml`) opens the [live app](https://sec-filings-rag-demo.streamlit.app) in a real browser after each push and once a day (waking it if it was asleep) and fails if the app shows an error.
